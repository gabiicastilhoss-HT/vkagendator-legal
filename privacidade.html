Política de Privacidade

VKagendator · Última atualização: 28 de setembro de 2026

O VKagendator é uma ferramenta de gestão de publicações para criadores de conteúdo. Ela permite organizar vídeos, aplicar edições padronizadas e agendar publicações em contas de redes sociais que pertencem ao próprio usuário.

Esta política explica quais dados o aplicativo trata, por quê, onde eles ficam guardados e como removê-los.

1. Quem opera o aplicativo

O VKagendator é operado pelo próprio usuário, em servidor sob seu controle. Não há serviço em nuvem centralizado coletando dados de múltiplos usuários: cada instalação guarda apenas os dados de quem a utiliza.

Contato para assuntos de privacidade: menegolvinicius@gmail.com

2. Dados tratados

2.1 Dados da conta no aplicativo

  • Nome e apelido
  • Endereço de e-mail
  • Senha, guardada apenas como hash criptográfico (bcrypt) — a senha original nunca é armazenada
  • Data de criação da conta

2.2 Dados das contas de redes sociais conectadas

Quando o usuário autoriza uma conta do Instagram ou do TikTok, o aplicativo recebe e guarda:

  • Identificador e nome de usuário da conta
  • Número de seguidores e de publicações
  • Token de acesso emitido pela plataforma, usado para publicar e ler métricas
  • Data da conexão e data de expiração do token

O token de acesso é fornecido pela própria plataforma após o usuário autorizar, e é usado exclusivamente para as ações que o usuário solicita no aplicativo.

2.3 Métricas públicas das publicações

Para exibir o painel de desempenho, o aplicativo consulta métricas das publicações da conta conectada, como visualizações, alcance, curtidas e comentários. São dados que a própria plataforma disponibiliza ao dono da conta.

2.4 Arquivos de vídeo

Vídeos importados ou processados pelo usuário são tratados para permitir a edição e a publicação agendada.

4. Compartilhamento com terceiros

O aplicativo não vende, aluga nem comercializa dados pessoais, e não os utiliza para publicidade ou criação de perfis comportamentais.

Há comunicação apenas com as plataformas necessárias para executar o que o usuário pede:

  • Meta / Instagram — para autorizar a conta, publicar conteúdo e ler métricas. Política do Instagram
  • TikTok — para autorizar a conta e publicar conteúdo. Política do TikTok

Ao publicar, o conteúdo é enviado à plataforma de destino e passa a ser regido também pelos termos dela.

5. Segurança

  • Senhas são guardadas apenas como hash bcrypt
  • As sessões usam tokens assinados, com expiração
  • A comunicação com as plataformas ocorre por HTTPS
  • O acesso ao aplicativo é restrito ao servidor do usuário

Nenhum sistema é totalmente imune a falhas. O usuário deve manter o servidor e o sistema operacional atualizados e restringir o acesso à máquina onde o aplicativo roda.

6. Direitos do usuário e exclusão de dados

O usuário pode, a qualquer momento:

  • Desconectar uma conta — em Conexões, a opção de remover apaga o token de acesso e os dados daquela conta do banco local
  • Apagar vídeos — pela Galeria, individualmente ou em lote
  • Cancelar agendamentos — na aba Agendados
  • Revogar o acesso pela própria plataforma — nas configurações de aplicativos do Instagram ou do TikTok, encerrando a autorização mesmo sem usar este aplicativo
  • Solicitar exclusão completa — pelo e-mail de contato acima

Como os dados residem no servidor do próprio usuário, a remoção é imediata e definitiva: não há cópias em serviços de terceiros.

7. Menores de idade

O aplicativo não se destina a menores de 18 anos e não coleta intencionalmente dados de crianças ou adolescentes.

8. Alterações nesta política

Mudanças relevantes serão refletidas nesta página, com atualização da data no topo.
